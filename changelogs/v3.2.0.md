# v3.2.0

- 新增图片处理设置 `recent_image_count`，默认 2，支持 0–20，0 关闭自动附带近期图片
- 每轮把当前会话最近可读取的用户图片直接作为视觉输入，附带消息 ID、时间、发送者和组件位置，选中记录不再只显示图片缺失占位
- 当前图片和明确引用图片优先保留，近期图片按来源去重，不因为本轮的已处理临时文件名不同而重复附图
- 同时支持概率回复、原生 @、私聊和观察回复；观察模式仍使用同一次模型调用决定是否参与并生成正文，不启用工具
- 近期图片与来源标签仅用于本轮，不写成重复的历史视觉附件，下一轮按当前记录重新选取
- 排除 bot 图片和晚于请求的消息，跳过本地缺失图片，不读取其他聊天、不额外调用识图模型或批量下载历史图片
