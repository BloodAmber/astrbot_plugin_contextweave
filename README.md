# ContextWeave · 群聊语境

基于 SpectreCore 2.1.13 的本地优化版本，版本 3.4.3。

### 3.4.3：修复旧消息补入后的顺序

- 补入的旧文字、引用和原图按来源消息时间归位，已有历史里的时间倒退也会在后续请求中整理
- 触发消息与其后续 assistant/tool 链作为整体移动，保留回复、工具调用及结果的原始关联，不单独排序工具结果
- 时间相同时维持原先顺序；没有可靠时间或来源的内容、人格示例及其他插件的独立内容保持边界，不猜测其归属
- 不修改系统规则或人格提示词，不读取或改写 LivingMemory 的记忆数据

### 3.4.2：回复排队与历史刷新

- 统一追踪原生 @ 回复和插件主动回复，覆盖工具执行、历史保存及发送；成功、失败、取消后随事件任务结束自动清理
- 忙碌时收到的普通消息仍会保存，但跳过本次主动回复；明确 @ 和单独 @ 邀请仍沿用 AstrBot 原生排队
- 插件预建请求在拿到 AstrBot 会话锁后刷新原生历史，保留已完成的工具结果和回复，避免用排队前的旧历史重复执行任务
- 刷新只替换原历史段，保留人格、引用、附件和观察指令，再执行原有图片及时间顺序整理；排队期间会话被重置或切换则跳过旧请求
保留内部插件标识和目录名 `spectrecore`，可原位升级。

## 上下文与图片

- 概率主动接话、观察回复、原生 @ 和私聊使用同一原生会话。
- 群聊按消息位置呈现，每条消息带发送者、时间和真实引用。原图直接放在它所属的消息中，不集中追加到本轮问题后。
- 默认保留最近 2 张可读取的用户原图，设置范围 0–20；当前图片和明确引用的附件另行保留。0 关闭自动提供近期原图。
- 已在原生历史中保存过的选中图片也恢复到原消息位置；不因去重而把图移到当前提问后。不额外寻找或追加历史参考图，也不替模型猜测“这个”指哪张图。
- 未被选中或不可读取的图片在原位置保留文字占位；本轮读取失败会明确标注。来源说明不代表模型一定能理解含糊指代，必要时应澄清。
- 图片沿用当前 AstrBot 缩放设置；动图标明原动画/抽帧拼图，说明紧邻原消息里的图片，不把抽帧网格当成原图自带的九宫格。
- 历史位置的视觉内容只在本轮提供，不累计存入对话数据库。下一轮按最新窗口重新选择，原消息的文字和身份仍保留。
- ContextWeave 自己以前保存的 `<contextweave_delta>` 文本块，在请求副本中展开成独立消息；不直接重写数据库，不读取其他插件的存储文件。
- 保留原有 Flow 兼容分支：仅替换它本轮刚注入的尾部增量，不修改 Flow 的代码或配置；无 Flow 时可独立运行。不新增对其他插件的依赖。
- 首轮回看默认 20 条，后续按消息 ID 补充未见记录，受本地 200 条保存范围和字符预算限制。较早的未见记录不直接丢弃；省略、截断会注明。
- 真实引用只按消息 ID 和成功的 QQ 发送回执追踪，最多 8 层并检测循环；不按引用文字、关键词或时间邻近猜测。断开的引用不会强行绑定最新图片。

## 系统规则设置

在插件设置 → 群聊语境组织 → 追加到系统提示词的固定规则中查看或编辑完整文本。默认与原固定规则相同；自定义内容直接替换原规则，留空表示不追加这一段。保存配置并按界面提示重载后生效。观察模式的 JSON 输出协议、本轮触发方式及动图来源说明不由此项控制，原有人格保持原样。

## 接话

- `model_frequency.method` 可选概率回复或观察回复。概率模式按概率/关键词触发一次接话机会，并不意味着群友在向机器人提问。
- 观察模式合并近期群消息，在一次模型调用中决定是否接话、关联哪条消息并生成正文；不调用工具、不显示判断 JSON，新增消息可使过期结果失效。
- 单独 @ 自己表示邀请参与当前讨论；@ 附正文、图片和私聊仍沿用原生入口，避免重复调用。
- 群黑白名单、临时静默和会话隔离保持原行为。
- 用户成功执行原生 `/reset` 或 `/new` 后，清理本插件对应的近期记录和发送回执；`/cw reset` 仅清理插件近期记录。

## 思考过滤

- `filter_thinking` 过滤助手开头的 `<think>` / `<thought>`，兼容大小写、空白、嵌套及分片；未闭合内容不交付聊天。
- 开头独占一行的 `🧠` 后没有明确正文边界时，整条拦截，不猜测最终答案。
- 推理字段、缓存和流式 reasoning 片段不交付聊天；请求副本中的旧助手泄漏也会清理，不改用户原文。
- 不保证识别没有任何标记的任意分析文字，不改变模型的实际思考能力或全局设置。

## 命令

使用 `/cw help` 或 `/contextweave help`，兼容 `/sc` 和 `/spectrecore`。
管理员可用 `/cw history` 查看近期记录、`/cw reset` 清理插件记录、`/cw mute 分钟` 和 `/cw unmute` 控制临时主动回复。
